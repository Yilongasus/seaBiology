# 國立海洋生物博物館形象官網
![Docker Image Size](https://img.shields.io/badge/Yilongasus-seaBiology-pink)

## 專案描述
這個專案是一個使用 Vue3 前端框架開發的海生館網站，站上資料主要來自政府資料開放平台的數據，切分多個頁面視覺化展示，個人練習Side Project，不提供任何商業用途。

## 專案功能
- 數據視覺化展示
- 響應式設計，適應各種設備
- LINE、Google第三方應用
